# Profile Photo

This repository contains an original profile photo.

## File

- `profile-photo.png` — the image file.

## Usage

Upload these files to your GitHub repository. If this photo belongs to someone else,
make sure you have their permission before publishing it publicly.

## Add to GitHub

1. Create a repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload `profile-photo.png` and `README.md`.
4. Commit the changes.
